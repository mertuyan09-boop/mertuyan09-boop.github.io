Privacy Policy

Siradan Gorunen Yukleyici · Last updated: 23 October 2026

YouTube API Services

Siradan Gorunen Yukleyici uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy applies to data processed by Google.

Data accessed

With the user's permission (Google OAuth 2.0) the tool uses two scopes:

  • youtube.upload – to upload videos to the signed-in channel and set their title, description, tags and scheduled publish time;
  • youtube.readonly – only to read the signed-in channel's ID and name, to confirm that uploads go to the correct channel.

No other YouTube or Google account data is accessed.

Data stored

The OAuth token, the channel ID and channel name, and the IDs and scheduled times of uploaded videos are stored only on the owner's own computer. Nothing is stored on any server, and no cookies or analytics are used.

Data sharing

No data is sold, shared with or transferred to any third party.

Revoking access and deleting data

  • Access can be revoked at any time at Google Account → Third-party connections (also via Google security settings). After revocation the stored token no longer works.
  • All stored data is deleted by deleting the local folder %LOCALAPPDATA%\SiradanGorunen\youtube and the yuklendi.json files. Stored data is kept only while the tool is in use and is deleted within 7 days of access being revoked.
